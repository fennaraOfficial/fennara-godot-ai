Não relate vulnerabilidades de segurança em issues públicas.

Para relatos confidenciais, envie um e-mail para:

```text
fennara.gamedev@gmail.com
```

Problemas confidenciais incluem:

- exposição de tokens ou credenciais
- acesso arbitrário a arquivos
- execução arbitrária de comandos
- gravações inseguras no projeto
- contorno de autenticação ou de direitos de acesso
- comportamento inseguro de lançamento ou atualização

Inclua uma descrição breve, etapas para reprodução, a versão ou o commit afetado e quaisquer logs ou capturas de tela relevantes.
