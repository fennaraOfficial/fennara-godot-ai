<a id="what-to-watch-for"></a>
## O que observar

A parte importante é o ciclo:

```text
inspect the project
make a change
receive Godot feedback
patch the mistake
continue
```

O MCP tradicional oferece comandos à IA.

O Fennara oferece à IA feedback do Godot.
