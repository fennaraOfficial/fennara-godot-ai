<a id="what-to-watch-for"></a>
## 观看时要关注什么

重要的是这个闭环：

```text
inspect the project
make a change
receive Godot feedback
patch the mistake
continue
```

传统 MCP 给 AI 命令。

Fennara 给 AI 来自 Godot 的反馈。
