请勿在公开 issue 中报告安全漏洞。

敏感报告请发送电子邮件至：

```text
fennara.gamedev@gmail.com
```

敏感问题包括：

- 令牌或凭据泄露
- 任意文件访问
- 任意命令执行
- 不安全的项目写入
- 绕过认证或授权
- 不安全的发布或更新行为

请附上简短说明、复现步骤、受影响的版本或提交，以及相关日志或截图。
