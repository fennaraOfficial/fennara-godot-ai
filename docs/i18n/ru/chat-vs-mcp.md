# MCP-приложения или встроенный чат?

Fennara поддерживает оба варианта. Выберите, где должен проходить разговор.

| | Внешнее MCP-приложение | Встроенный чат Fennara |
| --- | --- | --- |
| Где вы общаетесь | Codex, Claude, Cursor, Gemini или другое MCP-приложение | Панель Fennara или системный браузер |
| Учетная запись модели | Учетная запись или подписка внешнего приложения | Провайдер, подключенный в Fennara Chat Settings |
| Что добавляет Fennara | Инструменты MCP, учитывающие особенности Godot | Интерфейс чата, те же основные инструменты Godot, а также доступные только в чате инструменты для файлов и оболочки |
| Настройка | **Chat Settings > MCP Apps** | **Chat Settings > Chat > Open providers** |

> [!TIP]
> Можно использовать оба способа. Настройки их моделей остаются раздельными.

<a id="external-mcp-apps"></a>
## Внешние MCP-приложения

Подключение MCP-приложения позволяет этому приложению запускать локальный MCP-сервер Fennara и вызывать инструменты Godot. Оно не предоставляет встроенному чату доступ к подписке или входу во внешнем приложении.

Настройте приложение в **Chat Settings > MCP Apps** или используйте CLI:

```bash
fennara mcp-setup --codex
fennara mcp-setup --help
```

Ключ провайдера чата Fennara не требуется. Перезапустите внешнее приложение после настройки.
Все поддерживаемые приложения и ручная настройка описаны в разделе [Настройка MCP](mcp-setup.md).

<a id="built-in-chat"></a>
## Встроенный чат

Для встроенного чата нужен провайдер, подключенный в Fennara Chat Settings. Используйте собственный ключ облачного провайдера или подключите локальный сервер Ollama или LM Studio.

Один и тот же чат может отображаться на панели Godot или в системном браузере. Выбор места отображения не меняет его провайдера, модель, историю или проект.

Чтобы прикрепить код, выделите его в редакторе скриптов Godot, откройте контекстное меню и выберите **Add to Chat**. Настройка провайдера и модели описана в разделе [Провайдеры встроенного чата](providers.md).

<a id="project-routing"></a>
## Маршрутизация проекта

Оба способа используют локальный демон Fennara для получения обратной связи от Godot.

- Внешний MCP-процесс может однократно привязаться при запуске к каноническому
  Project Root Godot. Его вызовы направляются в соответствующий редактор, не читая и не
  изменяя **MCP target** на панели.
- Непривязанный внешний MCP-процесс сохраняет поведение совместимости: он
  использует выбранную на панели цель MCP Target, а если нет допустимой цели,
  единственный подключенный редактор.
- Встроенный чат остается привязанным к редактору Godot, который открыл этот чат.

Для изолированных агентов, работающих в отдельных репозиториях или рабочих
деревьях, используйте по одному MCP-процессу и подключению для каждого проекта. См.
[Несколько агентов и рабочих деревьев](multi-agent-worktrees.md), где описаны настройка и
поведение Runtime Slot.

Чтобы проверить внешнее MCP-подключение, отправьте запрос:

```text
Use Fennara MCP to run fennara_status and tell me which Godot project is connected.
```

Перед параллельной работой убедитесь, что в состоянии указаны режим маршрутизации
`bound` и ожидаемый канонический Project Root. Устаревший непривязанный режим содержит
предупреждение о параллельной работе.
