| Традиционный командный мост | Цикл обратной связи Fennara |
| --- | --- |
| Предоставляет действия редактора | Предоставляет исследование, действия и проверки с учетом особенностей Godot |
| Успешная команда может завершать рабочий процесс | Диагностика, проверка, журналы выполнения и снимки экрана определяют следующий шаг |
| Лучше всего подходит для прямых, заранее известных изменений | Лучше всего подходит, когда агент должен исследовать, изменить, проверить и восстановить |

Большинство MCP-серверов для Godot предоставляют ИИ-клиентам команды редактора.

Примеры:

- создать узел
- задать свойство
- открыть сцену
- сохранить сцену
- прочитать журналы
- сделать снимок экрана
- запустить проект
- подключить сигнал
- изменить карту ввода
- управлять материалами
- запустить тесты

Это полезно. Godot становится поверхностью API.

Но при настоящей разработке игр с ИИ сложность заключается не в том, может ли ИИ вызвать `set_property`.

Сложность заключается в том, может ли ИИ определить, что проект неисправен.

<a id="traditional-mcp-pattern"></a>
## Традиционный шаблон MCP

```text
ИИ вызывает команду редактора.
Редактор возвращает результат.
ИИ предполагает следующий шаг.
```

Это хорошо работает для небольших прямых изменений.

Пример:

```text
Переименуй Camera3D в MainCamera.
```

Но такой подход слабее для крупных задач проекта, когда агент должен исследовать архитектуру, редактировать скрипты, ресурсы и сцены, видеть сбои и восстанавливаться.

<a id="fennara-pattern"></a>
## Шаблон Fennara

```text
ИИ изменяет проект.
Приходит обратная связь Godot.
ИИ исправляет и повторно запускает, пока все не заработает.
```

Fennara сосредоточена на обратной связи:

- диагностика GDScript
- проверка сцен
- ошибки времени выполнения
- исследование дерева сцен
- свойства узлов
- исследование классов и API
- снимки экрана
- сформированные инструкции проекта
- рабочие процессы исправления и повторного запуска

<a id="the-difference"></a>
## Различие

Традиционный MCP для Godot спрашивает:

```text
Какие команды редактора следует предоставить?
```

Fennara спрашивает:

```text
Какая обратная связь нужна модели, чтобы успешно создавать проект внутри Godot?
```

Команды являются необходимой основой.

Обратная связь является преимуществом.
