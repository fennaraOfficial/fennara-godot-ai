# Анонимная телеметрия

Fennara отправляет небольшое анонимное событие активности не чаще одного раза
в сутки по UTC. Событие отправляется только после подключения совместимого
редактора Godot к локальному демону. Оно помогает сопровождающим измерять число
активных установок, использование поддерживаемых платформ и распространение версий.

Телеметрия включена по умолчанию. Чтобы отключить ее, откройте **Chat Settings > Chat > Anonymous
telemetry**. В headless-средах и автоматизированных средах можно задать одну из
следующих переменных:

```text
FENNARA_DISABLE_TELEMETRY=true
DO_NOT_TRACK=1
```

Переменная среды имеет приоритет над сохраненной настройкой интерфейса. Отключение
телеметрии прекращает отправку будущих событий и удаляет локальную идентификацию
телеметрии и состояние последней отправки. Если снова включить телеметрию, при
следующем подключении Godot будет создан новый случайный идентификатор.

<a id="event-contents"></a>
## Содержимое события

Событие `fennara_active_installation` содержит только следующие данные:

| Поле | Назначение |
| --- | --- |
| `schema_version` | Версия небольшого контракта полезной нагрузки телеметрии |
| `event` | Фиксированное имя события |
| `installation_id` | Случайный UUID, сформированный локально и не полученный из оборудования или учетных записей |
| `fennara_version` | Версия работающего демона |
| `godot_version` | Числовая версия Godot, например `4.6.3` |
| `platform` | `windows`, `macos` или `linux` |
| `architecture` | `x86_64` или `aarch64` |

Fennara не отправляет названия проектов, пути проектов, сведения об учетных
записях, запросы, сообщения чата, ключи провайдеров, названия моделей, названия
инструментов, аргументы инструментов, результаты инструментов, журналы, снимки
экрана, содержимое сцен, имена файлов или текст ошибок.

<a id="storage-and-transport"></a>
## Хранение и передача

Демон хранит случайный идентификатор и последний день успешной отправки по UTC
в общем каталоге данных приложения Fennara:

```text
Fennara/
  telemetry/
    state.json
```

Демон отправляет событие по HTTPS на адрес
`https://fennara.io/api/telemetry`. Получатель проверяет точный список разрешенных
полей и заменяет исходный UUID установки на HMAC, созданный на стороне сервера,
прежде чем переслать событие в PostHog. Для этого события профили пользователей
PostHog и геолокация по IP отключены.

Получатель Vercel неизбежно видит обычные сетевые метаданные при обработке
HTTPS-запроса. Эти метаданные не копируются в полезную нагрузку события PostHog.

<a id="delivery-behavior"></a>
## Поведение доставки

Телеметрия работает вне путей вызова инструментов Godot:

- Ограниченная очередь принимает сигналы активности без ожидания.
- Один фоновый рабочий процесс повторно использует единственный HTTP-клиент.
- Для запросов установлен короткий тайм-аут.
- Переполненная очередь, проблема файловой системы, сбой сети или отказ сервера
  спокойно переносятся и никогда не приводят к сбою инструмента Fennara.
- День по UTC записывается только после принятия события сервером, поэтому более
  позднее подключение Godot может повторить неудавшуюся доставку.
- При завершении работа ненадолго ожидает, затем отменяет рабочий процесс
  телеметрии, вместо того чтобы задерживать демон.

Одна установка соответствует одному сохраненному случайному UUID. Использование
Fennara на двух компьютерах считается двумя установками. Очистка данных приложения
Fennara или отключение с последующим включением телеметрии создает новый
идентификатор.

Число активных установок за месяц рассчитывается как количество различных
анонимных идентификаторов установки, отправивших хотя бы одно событие
`fennara_active_installation` в течение календарного месяца.
