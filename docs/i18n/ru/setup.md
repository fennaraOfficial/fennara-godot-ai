Установите Fennara, выберите место общения и подключите свой проект Godot.

> [!TIP]
> Большинству пользователей достаточно добавить аддон, открыть панель Fennara
> и нажать **Set Up Fennara**. В macOS используйте описанную ниже установку
> через CLI, чтобы избежать уведомления безопасности после загрузки ZIP-файла
> аддона вручную.

<a id="before-you-start"></a>
## Перед началом

| Требование | Когда оно нужно |
| --- | --- |
| Godot 4.5 или новее | Всегда |
| Windows x86_64, Linux x86_64 или macOS arm64 | Всегда |
| ИИ-приложение с поддержкой MCP | Только для внешнего использования MCP |
| Облачный ключ API, Ollama или LM Studio | Только для встроенного чата |
| .NET SDK, доступный как `dotnet` | Только для диагностики C# и предварительной проверки рантайма |

<a id="install-from-godot"></a>
## Установка из Godot

> [!IMPORTANT]
> В macOS аддон из выпуска содержит нативную библиотеку, которая в настоящее
> время не нотарифицирована Apple. При загрузке ZIP-файла аддона через браузер
> и его ручной распаковке macOS может сообщить, что не может проверить
> `libfennara.macos.editor` на отсутствие вредоносного ПО. Используйте
> [установку из терминала](#install-from-the-terminal-recommended-on-macos),
> чтобы избежать этого уведомления.

1. Загрузите `fennara-addon-latest.zip` из
   [последнего выпуска](https://github.com/fennaraOfficial/fennara-godot-ai/releases/latest)
   и скопируйте `addons/fennara/` в свой проект.
2. Откройте проект и выберите панель Fennara.
3. Нажмите **Set Up Fennara**.

Fennara устанавливает соответствующие локальные компоненты и подключает открытый
проект. Если более старый общий демон бездействует, настройка останавливает его
перед активацией соответствующей версии. Для переключения версии не должно быть
ни одного подключенного проекта. Настраиваемый проект обычно остается отключенным,
пока версии различаются. Если настройка сообщает о подключенном проекте, закройте
все остальные редакторы с включенной Fennara и повторите попытку. Если для
текущего проекта сохраняется устаревшее подключение, закройте и снова откройте
этот редактор, затем повторите попытку.
Если настройка завершается ошибкой, на панели доступны **Retry**, **Copy Report**
и **Open Logs**. Копируемые отчеты очищены и не содержат ключи API, содержимое
чата или файлы проекта.

> [!NOTE]
> Аддон остается в проекте. CLI, демон, MCP-сервер, журналы и общий рантайм
> браузера находятся в каталоге данных приложения Fennara вне проекта.

<a id="install-from-the-terminal-recommended-on-macos"></a>
## Установка из терминала (рекомендуется в macOS)

CLI устанавливает тот же аддон и является рекомендуемым способом установки
в macOS. Он позволяет избежать прохождения через карантин браузера и Finder,
которое приводит к описанному выше уведомлению о нативной библиотеке.

Установите CLI в Windows:

```powershell
irm https://raw.githubusercontent.com/fennaraOfficial/fennara-godot-ai/main/install.ps1 | iex
```

Или в macOS и Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/fennaraOfficial/fennara-godot-ai/main/install.sh | sh
```

Затем запустите Fennara внутри проекта:

```bash
cd path/to/your-godot-project
fennara install
```

Если вы уже распаковали аддон вручную в macOS и видите уведомление, закройте
Godot и удалите скопированную вручную папку `addons/fennara/` перед выполнением
`fennara install`. Это важно, поскольку CLI сохраняет существующий полный аддон,
вместо того чтобы заменять его.

Если проект уже содержит полный аддон Fennara, CLI сохраняет его и устанавливает
соответствующие локальные компоненты. В противном случае он также устанавливает
аддон текущего выпуска. Закрепление версии и автоматизация описаны в
[справочнике установки CLI](cli.md#install-a-project).

<a id="choose-how-you-use-fennara"></a>
## Выбор способа использования Fennara

| Способ | Учетная запись модели | Настройка |
| --- | --- | --- |
| Встроенный чат | Провайдер, подключенный в Fennara Chat Settings | [Подключить провайдера](#connect-the-built-in-chat) |
| Внешнее MCP-приложение | Собственная учетная запись модели или подписка приложения | [Подключить MCP-приложение](#connect-an-mcp-app) |
| Оба способа | Каждый способ сохраняет собственные настройки модели | Выполните оба раздела |

<a id="connect-the-built-in-chat"></a>
### Подключение встроенного чата

1. Откройте **Chat Settings > Chat**.
2. Выберите **Open providers**.
3. Подключите облачного провайдера с собственным ключом или подключите локальный
   сервер Ollama либо LM Studio.
4. Выберите модель.

Поддерживаемые провайдеры, ключи, URL-адреса локальных серверов и идентификаторы
моделей приведены в разделе [Провайдеры встроенного чата](providers.md).
Используйте `/provider` и `/model` для тех же действий из поля ввода.

Встроенный чат использует системный webview:

| Платформа | Webview |
| --- | --- |
| Windows | Microsoft Edge WebView2 Runtime |
| macOS | Системный WKWebView/WebKit |
| Linux | Общий рантайм CEF под управлением Fennara |

Команды `fennara install`, `fennara update` и `fennara doctor` проверяют эти
требования. Инструменты MCP продолжают работать, если необязательный встроенный
чат запустить не удается.

Чтобы использовать системный браузер, включите **Open chat in my system browser next
time** в Chat Settings и перезапустите Godot. Это меняет только место отображения
встроенного чата. Провайдер, история и подключение к проекту сохраняются.

Чтобы прикрепить код к следующему сообщению встроенного чата, выделите код
в редакторе скриптов Godot, откройте контекстное меню и выберите **Add to Chat**.

<a id="connect-an-mcp-app"></a>
### Подключение MCP-приложения

Откройте **Chat Settings > MCP Apps**, найдите свое приложение и нажмите
**Set Up**. Перезапустите приложение, чтобы оно могло загрузить Fennara.

Приложение также можно подключить из терминала:

```bash
fennara mcp-setup --codex
fennara mcp-setup --help
```

Если вашего приложения нет в списке, полный перечень поддерживаемых приложений
и форматы ручной конфигурации приведены в разделе [Настройка MCP](mcp-setup.md).

Внешние MCP-приложения используют собственные учетные записи моделей. Встроенный
чат использует провайдера, выбранного в Fennara Chat Settings. Различие описано
в разделе [MCP-приложения и встроенный чат](chat-vs-mcp.md).

<a id="verify-the-connection"></a>
## Проверка подключения

Откройте проект Godot, затем отправьте MCP-приложению запрос:

```text
Используй Fennara MCP, чтобы запустить fennara_status, и сообщи, какой проект Godot подключен.
```

Если указан неверный проект, выберите правильную цель MCP на панели Fennara.

<a id="update-fennara"></a>
## Обновление Fennara

Когда на панели появится кнопка **Update**, нажмите ее и следуйте подсказкам.
Fennara загружает и проверяет обновление, прежде чем попросить закрыть Godot.
После установки она снова открывает тот же проект и сохраняет предыдущую рабочую
версию до успешного завершения проверки обновления.

Чтобы выполнить обновление из терминала, закройте Godot и запустите:

```bash
cd path/to/your-godot-project
fennara update
```

> [!IMPORTANT]
> Если вы обновляетесь с Fennara v0.3.8 или более ранней версии, один раз
> переустановите CLI с помощью приведенной выше команды для своей платформы,
> прежде чем выполнять `fennara update`. Эти версии CLI обращаются к более
> не используемому тегу выпуска и не могут обнаружить актуальные выпуски.
> Переустановка CLI переключает последующие обновления на конечную точку GitHub
> Latest Release, не удаляя аддон проекта или настройки.

> [!IMPORTANT]
> В macOS один раз переустановите CLI перед обновлением с Fennara v0.3.11.
> Эта версия CLI отклоняет существующий пакет фреймворка до этапа самообновления.
> Переустановка заменяет только CLI и сохраняет аддон проекта и настройки.

Если проверка завершается ошибкой, используйте **Restore Previous Version**,
**Open Logs** или **Copy Report** на панели. Точные версии, подготовка и
восстановление прерванного обновления описаны в [справочнике обновления CLI](cli.md#update-a-project).

<a id="troubleshooting"></a>
## Устранение неполадок

<a id="an-install-or-update-failed"></a>
### Сбой установки или обновления

Скопируйте очищенный отчет с панели или покажите последний отчет в терминале:

```bash
fennara diagnostics
```

Идентификаторы операций, вывод JSON, записываемые поля и гарантии удаления
чувствительных данных описаны в разделе [Диагностика CLI](cli.md#inspect-health-and-failures).

<a id="fennara-is-not-found"></a>
### Команда `fennara` не найдена

Откройте новый терминал и выполните:

```bash
fennara doctor
```

Если команда по-прежнему недоступна, добавьте каталог `bin` Fennara в PATH.
Пути для каждой платформы приведены на [странице установки CLI](cli.md#install-the-cli).

<a id="windows-binaries-fail-before-starting"></a>
### Бинарные файлы Windows завершаются с ошибкой до запуска

Если бинарный файл Fennara сообщает об отсутствующей DLL `VCRUNTIME` или `MSVCP`,
коде завершения `-1073741515` или `0xc0000135`, установите Microsoft Visual C++
Redistributable 2015-2022 x64:

```text
https://aka.ms/vs/17/release/vc_redist.x64.exe
```

Это требуется только на компьютерах Windows, где отсутствуют эти DLL рантайма Microsoft.

<a id="a-release-requires-a-newer-cli"></a>
### Выпуск требует более новую версию CLI

Если самообновление CLI не может установить требуемую версию, повторно запустите
скрипт установки из раздела [Установка CLI](cli.md#install-the-cli), затем повторите команду.

<a id="the-addon-is-not-visible-in-godot"></a>
### Аддон не виден в Godot

Убедитесь, что следующий файл существует, затем снова откройте проект:

```text
addons/fennara/fennara.gdextension
```

<a id="fennarastatus-shows-the-wrong-project"></a>
### `fennara_status` показывает неверный проект

Откройте нужный проект и выберите его с помощью элемента управления MCP target на панели Fennara.

<a id="c-diagnostics-are-missing"></a>
### Отсутствует диагностика C#

Убедитесь, что проект содержит один однозначно определенный файл `.csproj`, `.sln` или `.slnx`, затем выполните:

```bash
dotnet --version
```

Схемы рантайма браузера, ручное восстановление и сведения о реализации приведены
в разделах [Архитектура](architecture.md), [Ручная установка](manual-install.md)
и [Частые вопросы](faq.md).
