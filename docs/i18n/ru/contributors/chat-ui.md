Эта папка содержит исходный код необязательного интерфейса чата внутри редактора.

Первая версия намеренно не требует сборки и использует обычные HTML, CSS и
JavaScript. Благодаря этому репозиторий OSS легко исследовать, а инструментальная
цепочка фронтенда не добавляется до того, как будут окончательно определены хост
webview и мост чата демона.

Упакованная копия находится в `godot_demo/addons/fennara/dist/`.

После изменения этой папки выполните:

```bash
node scripts/sync-chat-ui.mjs
```

<a id="design-notes"></a>
## Примечания по дизайну

- Соответствуйте интерфейсам редактора Godot: компактные элементы управления,
  спокойный контраст, малые радиусы, четкие состояния фокуса и отсутствие
  оформления главного блока в маркетинговом стиле.
- Используйте только локальные API демона и чата Fennara, не требуйте размещенных
  в интернете сервисов.
- Поддержка OpenRouter должна использовать предоставленный пользователем ключ,
  который хранится локально вне проекта Godot.
- Интерфейс должен оставаться полезным без подключения к модели: состояние,
  настройки, расшифровка беседы и состояния поля ввода по-прежнему должны быть видны.
