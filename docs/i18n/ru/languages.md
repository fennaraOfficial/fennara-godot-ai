<a id="what-is-translated"></a>
## Что переводится

Набор переводимых документов содержит основной README, каждую страницу
непосредственно в каталоге `docs/`, файлы `CONTRIBUTING.md`, `CONTEXT.md`,
`SECURITY.md` и шесть предназначенных для участников разработки README
подсистем.

Юридические тексты, уведомления сторонних компонентов, шаблоны issue, внутренние
инструкции агентов, формируемые инструкции проекта, тестовые фикстуры и
документация поставщиков сохраняются в исходной авторитетной форме. Сформированные
файлы и файлы, определяющие поведение, не являются самостоятельными источниками
перевода.

<a id="freshness-and-validation"></a>
## Актуальность и проверка

Каждая переведенная страница содержит путь к каноническому источнику и его хеш.
Навигация формируется из одного манифеста локалей, а стабильные явные псевдонимы
английских якорей сохраняют работоспособность глубоких ссылок при переводе
заголовков.

Выполните:

```bash
node scripts/sync-doc-navigation.mjs
node scripts/check-doc-i18n.mjs
```

Эти инструменты не переводят текст. Они только поддерживают метаданные навигации
и проверяют покрытие, актуальность, структуру Markdown, команды, ссылки, якоря,
блоки кода, таблицы и URL-адреса. Исправления от носителей языка приветствуются
через обычные pull request.

Обычная синхронизация сохраняет существующие хеши источников, поэтому после
изменения английского текста переводы остаются устаревшими до их непосредственного
обновления. После проверки всех девяти переводов одной измененной английской
страницы подтвердите только этот источник:

```bash
node scripts/sync-doc-navigation.mjs --accept-source docs/cli.md
```

CI запускает синхронизацию навигации в режиме проверки перед структурной
валидацией. При этом также проверяется, что каждый стабильный английский якорь
остается прикрепленным к соответствующему переведенному заголовку.
