<a id="what-to-watch-for"></a>
## На что обратить внимание

Главное здесь заключается в цикле:

```text
исследовать проект
внести изменение
получить обратную связь Godot
исправить ошибку
продолжить
```

Традиционный MCP предоставляет ИИ команды.

Fennara предоставляет ИИ обратную связь от Godot.
