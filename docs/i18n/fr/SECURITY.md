Veuillez ne pas signaler les vulnérabilités de sécurité dans les issues publiques.

Pour les signalements sensibles, écrivez à :

```text
fennara.gamedev@gmail.com
```

Les problèmes sensibles comprennent :

- l'exposition de jetons ou d'identifiants
- l'accès arbitraire aux fichiers
- l'exécution arbitraire de commandes
- les écritures dangereuses dans le projet
- le contournement de l'authentification ou des droits
- un comportement dangereux de publication ou de mise à jour

Ajoutez une courte description, les étapes de reproduction, la version ou le commit concerné, ainsi que les journaux ou captures d'écran pertinents.
