<a id="what-to-watch-for"></a>
## Points à observer

L'élément important est la boucle :

```text
inspecter le projet
effectuer une modification
recevoir les informations de Godot
corriger l'erreur
continuer
```

Un MCP traditionnel donne des commandes à une IA.

Fennara donne à l'IA des informations provenant de Godot.
