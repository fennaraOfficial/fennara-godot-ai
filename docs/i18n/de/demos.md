<a id="what-to-watch-for"></a>
## Worauf du achten solltest

Der wichtige Teil ist die Schleife:

```text
Projekt untersuchen
eine Änderung vornehmen
Godot-Feedback erhalten
den Fehler korrigieren
fortfahren
```

Traditionelles MCP gibt einer KI Befehle.

Fennara gibt der KI Feedback aus Godot.
