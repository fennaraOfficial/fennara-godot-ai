Bitte melde Sicherheitslücken nicht in öffentlichen Issues.

Sende vertrauliche Meldungen per E-Mail an:

```text
fennara.gamedev@gmail.com
```

Zu vertraulichen Problemen gehören:

- Offenlegung von Token oder Zugangsdaten
- beliebiger Dateizugriff
- beliebige Befehlsausführung
- unsichere Schreibvorgänge im Projekt
- Umgehung von Authentifizierung oder Berechtigungsprüfung
- unsicheres Release- oder Aktualisierungsverhalten

Füge eine kurze Beschreibung, Schritte zur Reproduktion, die betroffene Version oder den betroffenen Commit sowie alle relevanten Protokolle oder Screenshots bei.
