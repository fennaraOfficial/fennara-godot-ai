<a id="what-to-watch-for"></a>
## En qué fijarse

La parte importante es el ciclo:

```text
inspect the project
make a change
receive Godot feedback
patch the mistake
continue
```

Un MCP tradicional proporciona comandos a una IA.

Fennara proporciona a la IA información procedente de Godot.
