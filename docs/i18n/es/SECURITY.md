No informes de vulnerabilidades de seguridad en incidencias públicas.

Para enviar informes confidenciales, escribe a:

```text
fennara.gamedev@gmail.com
```

Se consideran problemas confidenciales:

- exposición de tokens o credenciales
- acceso arbitrario a archivos
- ejecución arbitraria de comandos
- escrituras no seguras en el proyecto
- omisión de autenticación o derechos de acceso
- comportamiento no seguro durante publicaciones o actualizaciones

Incluye una breve descripción, los pasos para reproducir el problema, la versión o el commit afectados y cualquier registro o captura de pantalla pertinente.
