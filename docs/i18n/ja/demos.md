<a id="what-to-watch-for"></a>
## 注目すべき点

重要なのは次のループです。

```text
inspect the project
make a change
receive Godot feedback
patch the mistake
continue
```

従来の MCP は AI にコマンドを与えます。

Fennara は AI に Godot からのフィードバックを与えます。
