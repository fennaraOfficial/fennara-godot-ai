セキュリティ脆弱性を公開 Issue で報告しないでください。

機密性の高い報告は次のメールアドレスへ送ってください。

```text
fennara.gamedev@gmail.com
```

対象には次の問題が含まれます。

- トークンまたは認証情報の漏えい
- 任意のファイルへのアクセス
- 任意のコマンド実行
- 安全でないプロジェクト書き込み
- 認証または権限確認の回避
- 安全でないリリースまたは更新処理

短い説明、再現手順、影響を受けるバージョンまたは commit、関連するログやスクリーンショットを含めてください。
