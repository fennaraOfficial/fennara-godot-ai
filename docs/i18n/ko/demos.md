<a id="what-to-watch-for"></a>
## 확인할 핵심

중요한 부분은 다음 루프입니다.

```text
inspect the project
make a change
receive Godot feedback
patch the mistake
continue
```

기존 MCP는 AI에 명령을 제공합니다.

Fennara는 AI에 Godot의 피드백을 제공합니다.
